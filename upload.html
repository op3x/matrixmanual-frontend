      How to export your file

      PLC: .L5X, .L5K, .scl, .st, .exp, PLCopen .xml, and .TcPOU. Tag lists: .csv and .xlsx. A tag-table XML is tags only, not the program. CAD: .step and .stp, .iges and .igs, and ASCII .dxf. Archives: a .zip of those files.

      .L5X and .L5K

      Export the controller program as .L5X. That file is an XML export of the program, including ladder. The older .L5K text export is the same kind of save, with the .L5K type. Upload the .L5X or .L5K file.

      .scl, .st, and .exp

      Export the blocks as .scl source. Generate source from the blocks, on a block or on the program blocks folder, and upload the .scl file that command writes. Structured text saved as .st or .exp is also accepted.

      .TcPOU

      Some PLC projects store each object as a .TcPOU file in the PLC project folder. Upload those files, or a zip of that folder. ManualOS reads the program text inside them.

      PLCopen .xml

      Export PLCopen XML from the project and upload the .xml file. That export is the program. It is often on the Project menu. A tag-table XML is not this export: it is tags only.

      .csv and .xlsx tag lists

      A tag list is a spreadsheet. The first row should name the columns, and one column should be the tag name. Address and description columns help. Save the controller tag table as .csv or .xlsx. A tag-table XML is tags only, not the program. A tag list has names and comments rather than the control logic, so the manual is shorter than one built from a full program export.

      .step, .iges, and ASCII .dxf

      From the CAD tool, use Save As or Export. Choose STEP (.step or .stp), IGES (.iges or .igs), or ASCII DXF (.dxf). STEP AP214 and AP242 are both fine. STEP and IGES are the 3D model. DXF is a 2D drawing. You can zip several of them.
