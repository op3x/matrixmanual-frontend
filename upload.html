      How to export your file

      Upload the exported program or model, or a zip of those files. ManualOS does not accept Mitsubishi GX Works .gx3 files, Omron CX-Programmer .cxp files, or Siemens .zap15 archives.

      Rockwell Studio 5000 (L5X, and why ACD is limited)

      In Studio 5000 Logix Designer, open the controller and use File, then Save As. Set the file type to L5X. The older L5K text export is the same Save As command with the L5K type. Upload the .L5X or .L5K file.

      An .ACD file is the Studio 5000 project. The rung logic is stored in a proprietary form, so a manual made from ACD alone is incomplete and will say so. Export L5X when you can. Upload an ACD only if you cannot export L5X.

      Siemens TIA Portal (SCL)

      Export the blocks as SCL source (.scl). In TIA Portal the usual command is “Generate source from blocks”, on the block or on the program blocks folder. Upload the .scl file that command writes. A TIA archive (.zap15) is not accepted.

      Beckhoff TwinCAT (TcPOU)

      TwinCAT stores each PLC object as a .TcPOU file in the PLC project folder. Upload those files, or a zip of that folder. ManualOS reads the program text inside them.

      CODESYS and PLCopen XML

      Export PLCopen XML from the project and upload the .xml file. In CODESYS 3 that export is on the Project menu. Other IEC 61131-3 tools that write PLCopen XML use the same upload. Structured text saved as .st or .exp is also accepted.

      CSV and Excel tag lists

      A tag list is a spreadsheet. The first row should name the columns, and one column should be the tag name. Address and description columns help. Save the controller tag table as .csv or .xlsx. A tag list has names and comments rather than the control logic, so the manual is shorter than one built from a full program export.

      STEP, IGES, and DXF

      From SolidWorks, Inventor, Fusion, Creo, NX, AutoCAD, or a similar tool, use Save As or Export. Choose STEP (.step or .stp), IGES (.iges or .igs), or DXF (.dxf). STEP AP214 and AP242 are both fine. STEP and IGES are the 3D model. DXF is a 2D drawing. You can zip several of them. Native files such as .sldprt, .ipt, or .dwg are not accepted.
