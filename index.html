03

Some people can fix anything. Here’s what they know.

Great technicians don’t guess. They read the machine: what it was told to do, what stopped it, and what has to be true before it runs again.

That instinct takes years to build and one shift change to lose, or a retirement, or a contractor who moved on. ManualOS doesn’t replace it. It writes down what the machine already knows, so every technician starts from the program’s logic instead of a blank page.

04 Accepted today

Supported formats

PLC: .L5X, .L5K, .scl, .st, .exp, PLCopen .xml, and .TcPOU. Tag lists: .csv and .xlsx. A tag-table XML is tags only, not the program. CAD: .step and .stp, .iges and .igs, and ASCII .dxf. Archives: a .zip of those files.

Accepted file formats
Ref Format Files Notes
01 PLC program export .L5X .L5K XML export, including ladder
02 Structured text .SCL .ST .EXP IEC 61131-3
03 PLC object .TcPOU
04 PLCopen XML .XML Program export
05 Tag list .CSV .XLSX A tag-table XML is tags only, not the program.
06 CAD .STEP .STP .IGES .IGS .DXF DXF is ASCII. STEP and IGES are the 3D model. DXF is a 2D drawing.
07 Zip .ZIP A zip of the files above

05 How it works

From file to manual in three steps

You upload the file. ManualOS writes the manual.

  1. 01

    Upload the file

    After checkout, upload a file from the supported list, or a .zip of those files.

  2. 02

    ManualOS writes the manual

    It reads the routines, tags, and comments in the file and drafts a plain-English explanation of what the equipment does.

  3. 03

    Download the PDF

    You get a manual you can print, hand to a technician, or leave with the machine.

Questions

Which files can I upload?

PLC: .L5X, .L5K, .scl, .st, .exp, PLCopen .xml, and .TcPOU. Tag lists: .csv and .xlsx. A tag-table XML is tags only, not the program. CAD: .step and .stp, .iges and .igs, and ASCII .dxf. Archives: a .zip of those files.

What is in a manual?

You get a PDF operating and maintenance manual. The 60-page sample on this page is the SAMPLE-A Case Packer from Example Machinery Co. (fictional), document OM-SAMPLE-A-EN. It includes safety, machine description and theory of operation, transport, installation, commissioning, controls, operation, alarms and troubleshooting, maintenance, spare parts, and appendices. Where a sentence is tied back to the PLC program, the manual shows a code reference note.

What counts as one manual?

One generation run is one manual: one upload of up to 25 files or a .zip, whether those files are PLC, CAD, or both. A failed run doesn’t use a credit.
